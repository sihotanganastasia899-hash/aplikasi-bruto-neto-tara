# Aplikasi Pembelajaran Bruto, Neto, dan Tara

## Tentang Aplikasi

Aplikasi ini merupakan media pembelajaran matematika berbasis web untuk siswa SMP yang membahas materi Bruto, Neto, dan Tara.

Aplikasi dirancang agar siswa dapat belajar dengan mudah melalui materi sederhana, ilustrasi interaktif, contoh soal, dan latihan soal.

## Tujuan

- Memahami pengertian bruto, neto, dan tara.
- Mengetahui hubungan antara bruto, neto, dan tara.
- Mampu menggunakan rumus dengan tepat.
- Melatih kemampuan literasi matematika dalam kehidupan sehari-hari.

## Fitur Aplikasi

1. Login menggunakan kode siswa.
2. Materi pembelajaran.
3. Ilustrasi interaktif.
4. Contoh soal bertahap.
5. Latihan soal.
6. Petunjuk dan pembahasan.
7. Hasil belajar siswa.

## Teknologi

- React dan JavaScript untuk frontend.
- Python dan FastAPI untuk backend.
- Supabase untuk database.
- Three.js untuk ilustrasi 3D.

## Pengguna

Siswa SMP yang mengakses aplikasi melalui smartphone atau laptop.

## Status Pengembangan

Aplikasi masih dalam tahap perencanaan dan pengembangan.
